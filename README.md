# 🏠 租房看房记录表（整租）

**使用建议**：  
- 打印后带笔/手机填写，或直接在手机备忘录复制使用。

## 🌡️ 季节点检（根据看房季节勾选）

### 夏季看房重点
- [ ] 空调制冷能否快速降温（开机后测试温度变化）  
- [ ] 空调室外机噪音（是否影响卧室休息）  
- [ ] 顶层是否暴晒（手摸天花板温度，顶层夏天可能变蒸笼）  
- [ ] 西晒房间下午温度（西向窗户是否过热）  
- [ ] 纱窗完好（防蚊虫）  

### 冬季看房重点
- [ ] 暖气片数量/地暖覆盖范围（每个房间都要摸）  
- [ ] 暖气温度是否达标（自采暖需问燃气费用）  
- [ ] 窗户密封性（手背靠近窗缝感受冷风）  
- [ ] 墙体是否有冷桥（外墙内侧墙面温度）  
- [ ] 热水器冬季供水温度及升温速度  
- [ ] 是否有浴霸/暖风机  

### 雨季/回南天看房重点
- [ ] 天花板/墙角是否有漏水水渍（尤其是顶层/边套）  
- [ ] 窗户边缘是否有渗水痕迹  
- [ ] 地下室/一楼是否返潮  
- [ ] 阳台排水是否通畅（下水口有无堵塞）  
- [ ] 墙体是否有返碱/剥落（潮湿后遗症）  
- [ ] 室内湿度体感（是否闷湿黏腻）

## 🎯 议价与谈判策略

### 有效砍价理由（按说服力排序）
- [ ] 一次性付半年/一年（房东最看重现金流稳定）  
- [ ] 长租承诺（2-3年，房东省去找租客成本）  
- [ ] 房屋硬伤（采光差、临街噪音、无电梯高层等客观缺陷）  
- [ ] 不要求添置新家具家电（减少房东投入）  
- [ ] 可自行负责小修小补（写进合同）  
- [ ] 周边同户型成交价对比（提前在贝壳/链家查历史成交）  
- [ ] 房东挂牌时间较长（说明价格偏高，有谈判空间）  

### 额外争取项（不一定减房租，但可争取）
- [ ] 免租期（搬家过渡，通常3-7天）  
- [ ] 包物业费/网费  
- [ ] 免费停车位  
- [ ] 提供/更换必要家具（洗衣机、冰箱、床垫）  
- [ ] 押一付一（缓解现金流压力）  
- [ ] 书面承诺一定期限内不涨租  

### 谈判红线（试探房东底线的问法）
- [ ] "如果不包物业费，月租最低能到多少？"  
- [ ] "如果我一次付半年，能优惠多少？"  
- [ ] "这个价格是底价吗？还是可以再商量？"  
- [ ] "上一个租客的租金是多少？"
