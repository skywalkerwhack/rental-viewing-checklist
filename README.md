# 🏠 租房看房记录表（整租）

**使用建议**：  
- 打印后带笔/手机填写，或直接在手机备忘录复制使用。  
- 带上：卷尺、手电筒、手机测速软件、温湿度计（可选）、口罩（闻味时）。  
- 尽量选择上午或下午有阳光时段看房，并尽量在高峰时段观察交通与电梯。  
- **看房时关掉全屋所有灯**，才能看到真实自然采光——房东/中介惯用灯光掩盖暗间缺陷。    
- 如果对某套房有意向，**建议不同时间段再看一次**（工作日晚上、周末白天），观察楼道整洁度、邻居是否吵闹、小区真实生活氛围——一次看房只能看到冰山一角。  
- **避开甲醛房技巧**：看房时拍下水表读数，正常住人每月用水约 3~4 吨/人。水表读数极低或为零，说明长期无人居住，很可能是刚装修完的"甲醛新房"——入住对健康危害极大。

## 🔌 家电与设施（逐项试用/询问）

### 厨房
- [ ] 灶具类型（燃气灶/电磁炉/电陶炉）：  
- [ ] 抽油烟机吸力（可烧水测试）：  
- [ ] 冰箱容量及制冷效果：打开门感受冷藏/冷冻温度，闻有无异味  
- [ ] 冰箱运行噪音：**压缩机启动后站在冰箱旁仔细听**，正常为均匀低沉的嗡嗡声。如有哒哒声、金属摩擦声、间歇性巨响，说明压缩机/风扇老化，夜深人静时会很折磨人  
- [ ] 橱柜储物空间（是否防潮）：  
- [ ] 水槽下是否漏水（查看柜底）：  
- [ ] 燃气管道/阀门是否安全（有无老化、是否有报警器）：  
- [ ] 台面空间是否够用：  
- [ ] 是否有洗碗机/烤箱等额外电器：  

### 卫生间
- [ ] 热水器类型（电热/燃气/太阳能）：  
- [ ] 出热水速度：**打开热水龙头到最大，数秒**——5 秒内出热水为佳，超过 15 秒说明管道长/热水器老化，冬天每次洗脸都得先放一盆冷水  
- [ ] 水温是否可调、调节是否灵敏（旋钮/触控是否好用）：  
- [ ] 热水稳定性（多人连续洗是否变冷）：  
- [ ] 水压与水量：**同时打开厨房和卫生间所有水龙头到最大**，观察每个龙头的水流大小和力度是否正常、稳定。水流细弱/忽大忽小说明水压不足或管道有问题，洗澡时会很难受  
- [ ] 马桶冲水力度：**连续冲水 2~3 次**，观察每次冲力是否稳定、下水速度是否顺畅（堵点往往在连续冲时才暴露）。第一次进水箱补满后立即冲第二次，看水箱进水速度是否跟得上、有无异响  
- [ ] 马桶是否漏水：冲水后静置听有无滋滋渗水声，手摸水箱底部/水管接口处，用干纸巾擦拭连接处测试是否有湿痕  
- [ ] 马桶底座及周边：**蹲下查看马桶底座与地面接缝处**，有无水渍、发黑、霉斑、密封胶脱落。用干纸巾沿底座一圈擦拭，检测有无渗水痕迹——底座渗漏会慢慢泡烂地板，维修麻烦且费钱  
- [ ] 地漏排水速度：**打开水龙头快速放水进洗手台、浴室地漏、厨房水槽**，看水流下是否顺畅、有无积水反溢。排水慢或有咕噜咕噜声说明管道半堵，日后极易彻底堵塞  
- [ ] 卫生间反味：**关门半小时后开门闻一下**，有无下水道臭味、尿骚味。反味通常源于地漏水封干涸、洗手台下水管无存水弯、马桶密封圈老化——入住后持续反味极影响生活质量且难根治  
- [ ] 洗澡空间（站立转身是否局促）：  
- [ ] 是否干湿分离（浴帘/玻璃隔断，淋浴区有无挡水条或下沉式设计，水是否会漫到马桶/洗手台区域）：  
- [ ] 排气扇是否正常工作：  
- [ ] 镜柜/收纳是否够用：  

### 卧室/客厅
- [ ] 空调制冷效果：**开机制冷模式，设定最低温，运行 ≥15 分钟**。用手/纸巾放在出风口感受风力与温差；有条件的用温度计测出风口温度（制冷正常应低于 12~14℃）。15 分钟后房间整体温度应有明显下降，否则制冷剂可能不足  
- [ ] 空调制热效果：**切换制热模式，设定最高温，同样运行 ≥15 分钟**。出风口应吹出明显热风（制热正常在 40~55℃）。冷暖两用机型分别测试，不能只看制冷  
- [ ] 空调外机噪音：在室外机附近听运行声音，**制冷和制热模式分别听**。正常应为均匀的运转声+风扇声；如有咔咔、哒哒、金属摩擦等异响，说明压缩机/风扇有问题。同时回到卧室内，关窗后听是否仍有明显外机噪音穿透  
- [ ] 空调排水：制冷运行 15 分钟后检查室内机下方/排水管是否滴水或渗水（排水管堵塞/破裂的常见表现）  
- [ ] 空调异味：制冷刚开始吹出时闻一下，是否有霉味、酸臭味（蒸发器发霉或滤网长期未洗）  
- [ ] 空调品牌及购买年份（影响能耗）：  
- [ ] 洗衣机（波轮/滚筒，是否干净）：  
- [ ] 洗衣机位置：**从卧室走到洗衣机旁判断距离**——脱水时噪音和震动是否会穿透到卧室。若洗衣机在开放式厨房或紧邻卧室墙面，晚上洗衣服可能吵到睡觉  
- [ ] 床垫：**掀开床单/床笠，从四个角逐一翻起床垫查看**——正面有无无法清洗的污渍（血迹、尿渍、霉斑等）、是否有明显塌陷或弹簧凸起；翻开背面检查有无虫蛀痕迹、发霉、骨架断裂。床垫是个"很难换的贴身物"，有隐患果断要求房东更换  
- [ ] 衣柜门轨是否顺畅、内部隔层：  
- [ ] 沙发/桌椅是否稳固、有无破损：  
- [ ] 窗帘遮光程度（白天拉上测试）：  
- [ ] 电视/网络机顶盒是否可用：  

### 电力与网络
- [ ] 插座通电测试：**带手机充电器，逐个插上每个面板的每个孔位**（包括床头、书桌、厨房、阳台等），确认都能正常通电。部分老房子面板松动/接触不良肉眼看不出来，只有插上才现原形  
- [ ] 插座数量（每个房间几个，是否够用）：  
- [ ] 插座位置是否合理（床头/书桌/厨房）：  
- [ ] 是否有USB插座或带开关插座：  
- [ ] 网络运营商（电信/移动/联通/其他）：  
- [ ] 现场测速（下载/上传/延迟）：  
- [ ] 手机信号：**拿着手机走到每个房间的每个角落**（包括卫生间、厨房深处），看是否都有信号。不同运营商信号差异可能很大  
- [ ] 网络接口：逐个查看各房间的 RJ45 网口面板，如有笔记本电脑可带网线/转接头实测是否通网——有些老房子墙上网口只是装饰  
- [ ] 是否有智能家居（门锁、灯、窗帘等）：

## 🐜 卫生与隐患（仔细检查隐蔽角落）
- [ ] 蟑螂/蚂蚁踪迹（橱柜角落、冰箱后、灶台缝隙）：  
- [ ] 老鼠迹象（粪便、咬痕、天花板声响）：  
- [ ] 其他虫害（蚊虫、白蚁）：  
- [ ] 墙角/踢脚线霉菌（尤其背阴面）：**沿着所有墙角、窗户边缘、天花板接缝处用手仔细摸一圈**——感受是否有潮湿、鼓包、掉皮、粉化，这些都是漏水/渗水的后遗症。重点关注天花板角落（楼上漏水常见位置）和窗户四角（密封失效导致渗水）  
- [ ] 橱柜霉味：**逐一打开厨房和卫生间的每个橱柜门**，弯腰凑近闻——有霉味/潮味说明水槽或管道曾经漏水，柜体内部可能已受潮变形甚至腐烂。尤其注意水槽正下方的柜底，用手指按压木板感受是否发软  
- [ ] 厨房油污（抽油烟机滤网、墙面）：  
- [ ] 前租客遗留物品/垃圾未清：  
- [ ] 空调滤网是否积灰（影响健康）：  
- [ ] 卫生间天花板/墙面是否有水渍或发黑：

## 🔊 噪音与隔音效果（容易被忽略）

### 室内隔音检查
- [ ] 墙体隔音：**握拳用力敲击所有隔墙**（包括卧室之间、与邻居共用的墙壁）——实心墙声音沉闷、回弹硬，空心墙声音空洞带回声。空心隔断墙隔音极差，邻居说话/走路都能听到  
- [ ] 窗户隔音：关闭所有窗户后，站在窗边听外界声音变化。双层/中空玻璃隔音效果明显优于单层  
- [ ] 地板/天花板隔音：在房间里正常力度走路、跺脚，感受是否有明显空响或共振。木质架空层 vs 混凝土楼板的隔音差异极大  
- [ ] 管道噪音：到卫生间/厨房，请同行人打开水龙头放水，自己留在卧室听管道水声是否明显（尤其关注卧室紧邻卫生间的户型）  
- [ ] 门隔音：关上入户门后，在门内听楼道/电梯厅的声响。厚重门 vs 轻飘飘门的隔音差很多  

### 外部噪音
- [ ] 临街/临主干道噪音：  
- [ ] 楼上/隔壁是否有装修或长期噪音源：  
- [ ] 是否靠近学校、酒吧、夜市、工地：  
- [ ] 电梯井/管道井是否紧挨卧室：  
- [ ] 夜间是否有明显噪音（建议晚间再观察一次）：  
- [ ] 空气质量（是否靠近高架、工厂、垃圾站）：

## 🗣️ 邻居探访（看房后可选，但强烈建议）
- [ ] 楼上邻居：是否有小孩/宠物，脚步声大否（可敲门简短交流）  
- [ ] 隔壁邻居：作息习惯、是否经常聚会  
- [ ] 对门邻居：房屋居住情况（自住还是多户合租）  
- [ ] 楼下/小区老人：社区治安、物业服务质量评价  
- [ ] 楼道是否堆放杂物、地面是否干净（消防安全隐患，也反映邻里素质和物业管理水平）  
- [ ] 电梯里遇到的居民态度（是否友好、是否抱怨过什么问题）  
- [ ] 居委会/物业办公室：是否有近期投诉记录  

> 💡 技巧：假装咨询小区情况（如"这边物业怎么样？""附近超市在哪？"），自然打开话匣子
